# エラトステネスのふるい

1〜210の素数を視覚的に発見するインタラクティブツール

🔗 **公開URL**: https://sieve.meetupsensei.com/

## 概要

「エラトステネスのふるい」のアルゴリズムを、数字のグリッドをアニメーションさせながらステップごとに体験できるツールです。素数の発見と、その倍数を順番に消していく過程を視覚的に確認できます。右側の履歴パネルには各ステップの操作内容が記録され、下部には発見した素数の個数や経過ステップ数が表示されます。グリッドの列数や数字の上限（100・210・500）も自由に変更できます。

## 使い方

- 「開始」ボタンを押すとアルゴリズムがスタートします
- 「次のステップ」ボタンで1ステップずつ手動で進められます
- 「自動実行」ボタンを押すと、選択した速度（遅い・普通・速い・超速）で自動的に進行します
- 「リセット」ボタンでいつでも最初からやり直せます
- 「列数」「上限」の設定は、開始前であれば自由に変更できます
- グリッド上の色分け（未チェック・現在の素数・素数・素数でない）は凡例で確認できます
